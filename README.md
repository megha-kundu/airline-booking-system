# ✈️ Airline Booking System

A modern full-stack Airline Booking System that allows users to search flights, book tickets, and manage reservations through a responsive and user-friendly interface. The application is built using HTML, CSS, JavaScript, Bootstrap, Node.js, Express.js, and MongoDB, providing a complete booking experience from flight search to confirmation.

## 🚀 Features

- User Registration and Login
- Search flights by source, destination, and travel date
- View available flights with detailed information
- Book flight tickets online
- Passenger information management
- Booking confirmation with email notifications
- Responsive design for desktop, tablet, and mobile devices
- Secure backend built with Node.js and Express.js
- MongoDB database for storing users and booking information

## 🛠️ Technologies Used

### Frontend
- HTML5
- CSS3
- JavaScript
- Bootstrap

### Backend
- Node.js
- Express.js

### Database
